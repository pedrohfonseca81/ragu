# Acme Knowledge Base (example)

This folder is what `npx create-ragu` copies, and doubles as the example project for the Ragu repository. The docs describe a fictional bookshop with two systems, `api` and `web`.

```bash
npm install
npm run dev      # site
npm run check    # fast validation
npm run build    # full validation + static site
```

See the [Ragu README](../README.md) for the whole story.
